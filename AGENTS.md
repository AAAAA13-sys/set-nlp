# EvaluaTech repository agent guide

This file is the primary repository entry point and multi-tier engineering guide for **EvaluaTech / PLP EvaluTech** (Automated Student Evaluation of Teachers with Dual-Token Cryptographic Decoupling, AACCUP Level III Governance, and `calamanCy` + VADER NLP Sentiment Analytics for **Pamantasan ng Lungsod ng Pasig**). For changes spanning the Laravel 12 / standalone PDO backend, Vue.js 3 SPA frontend (`resources/js/`), and Python/Flask NLP microservice (`analytics/`), apply all rules in this guide and its linked `.agents/` skills.

## Before editing

1. Check `git status` and read [`implementation plan.md`](implementation%20plan.md) and [`NLP-SET Online.txt`](NLP-SET%20Online.txt) to preserve existing work and align with the active architectural phase.
2. Trace the affected API route (`routes/api.php` and standalone router in `public/index.php`), middleware (`EnsureRole`, `EnsureDoubleBlindUnlocked`, `SecurityHeadersMiddleware`), Form Request validator, controller (`app/Http/Controllers/Api/`), domain service (`app/Services/`), Eloquent model, Vue Router guard (`resources/js/router/index.js`), Pinia store (`resources/js/stores/`), Vue view/component, Python endpoint (`analytics/app.py`, `analytics/engine.py`), and automated tests. Search every caller of a shared contract before changing its signature or payload shape.
3. Make the smallest complete, surgical change using established service and store patterns. Update all affected API consumers, Vue components, and multi-tier tests in the same change.

## Architectural boundaries

- **Laravel 12 & Standalone HTTP Runtime (`app/`, `routes/`, `database/`, `public/index.php`)** owns stateless HMAC-SHA256 Bearer authentication (`EVT.*` tokens via `AuthController` + `EvaluaTechDemoSeeder`), five-role RBAC (`admin`, `dean`, `chair`, `faculty`, `student`), atomic CSV/JSON academic roster ingestion, dynamic evaluation queue generation, administrator-controlled evaluation window schedules (`starts_at`, `ends_at`, `Asia/Manila`, `EXTEND` vs `REOPEN`), non-negative elapsed duration and straight-line variance validation, atomic dual-token database transactions, bulk Registrar grade-lock synchronization, cryptographically sealed AACCUP Level III evidence dossiers (`PLP-AACCUP3-*`), public proctor examination permit verification (`/api/permit/verify`), and 63-control OWASP / AI security enforcement (`SecurityHeadersMiddleware`, `SecurityAuditService`). Controllers map HTTP input/output only; domain logic belongs in `app/Services/`.
- **Vue.js 3 SPA (`resources/js/`, `resources/views/app.blade.php`, `resources/css/app.css`)** owns the reactive user interface across mobile ($375\times812\text{ px}$) and desktop ($1366\times768\text{ px}$) viewports using Vue 3 Composition API, Pinia stores, and Vue Router:
  - **Public Institutional Landing Page (`/` / `LandingView.vue`)**: Professional, school-based public landing page introducing EvaluaTech, the Pamantasan ng Lungsod ng Pasig SET mission, AACCUP Level III accreditation governance, and cryptographic student anonymity charter, providing clear "Sign In" access (`/login`) for students, faculty, and academic staff.
  - **Single-Page Universal Top-Bar Navigation (`NavbarHeader.vue` in `resources/js/app.js`)**: Clean, responsive institutional top navigation bar across all roles (`student`, `faculty`, `chair`, `dean`, `admin`) and unauthenticated views. Zero sidebars, zero collapsible side rails, and zero mobile side navigation drawers. On mobile, uses an accessible dropdown menu expanding beneath the top bar.
  - **Academic Tech Split-Screen Login (`LoginView.vue`)**: Full-viewport 50/50 split-screen (`PLP EvaluTech` deep forest-green geometric mesh + grain narrative panel paired with warm `#F9F9F8` canvas, floating card, floating-label inputs, pill CTA, RA 10173 compliance callout, open-redirect sanitization, and `sessionStorage`-first ephemeral auth with zero demo/cheat buttons).
  - **Student Workspace & Immediate Two-Step Stepper (`StudentQueueView.vue`, `EvaluationFormView.vue`)**: Full-width, distraction-free workspace without side rails, without permit banners, and with an immutable 2-step evaluation stepper (Part I: 25 Likert scale questions with incomplete rating detection and pulse auto-scroll; Part II: left-aligned written feedback and instant submit with loading state). Students assess teachers whenever ready ($0\text{s+}$ dwell duration).
  - **Evaluation Participation Tracking (Zero Permits Policy)**: The university does not issue or gate examination permits. The system focuses on **Evaluation Participation Tracking** — identifying students with pending evaluations and showing completion progress by course, section, department, and college, subject to strict role permissions, without exposing student-to-response links.
  - **Focused Fullscreen & Managed Kiosk Separation**: Browser fullscreen mode (`document.documentElement.requestFullscreen()`) provides a voluntary focus aid for personal devices with graceful degradation. Supervised computer laboratory environments implement OS/browser kiosk modes independently (documented in `docs/MANAGED_KIOSK_DEPLOYMENT.md`), never conflating browser tabs with hardware-level lockdowns.
  - Local draft autosave (`evaluatech_draft_sec_*` with zero PII), debouncing, throttling, and zero-variance modals improve UX ergonomics, but never replace server-side enforcement.
- **Python / Flask NLP Microservice (`analytics/`)** owns `calamanCy` (`https://github.com/ljvmiranda921/calamanCy` — Tagalog/Taglish/English spaCy pipeline target with active heuristic morphological fallback) + VADER sentiment polarity calculation ($P \in [-1.0, +1.0]$), valence classification (`Positive`, `Neutral`, `Negative`), dual-stream score combination ($0.60 \times \text{rule} + 0.40 \times \text{vader}$ with zero premature returns), explicit runtime provenance reporting (`calamancy_loaded`, `fallback_heuristic`, `runtime_engine`, loaded dependencies), five-cluster pedagogical tagging (*Pedagogical Delivery*, *Assessment & Grading*, *Classroom Management*, *Professional Conduct*, *Student Support & Mentorship*) alongside explicit `Unclassified / Needs Review` isolation for non-teaching campus facilities and extracurricular feedback, structured synthesis of the 4-to-5 professor qualitative questions (`three_words`, `room_for_improvements` with sub-topics `a.`, `b.`..., `teaching_strengths`, `recommendations`, capped at `max: 5`), automated pedagogical action plan generation, and PII/prompt-delimiter scrubbing (`scrub_pii`). Evaluated on an untouched 240-row held-out test partition ($62.08\%$ accuracy, $48.39\%$ negative recall, $0.072\text{ ms}$ latency). Production daemon binds strictly to `127.0.0.1:5001` with `debug=False` and bounded payload/batch quotas (`MAX_COMMENT_LENGTH = 2000`, `MAX_BATCH_SIZE = 250`).
- **MySQL 8.0 InnoDB / Isolated SQLite PDO (`database/migrations/`, `database/seeders/EvaluaTechDemoSeeder.php`)** owns relational persistence, foreign-key integrity on catalog and clearance tables, row-level pessimistic locking (`SELECT ... FOR UPDATE`), sliding-window auth rate-limit state (`auth_rate_limits`), zero-PII security telemetry (`security_audit_logs`), webhook replay deduplication (`webhook_replays`), and strict physical separation between `evaluation_clearances` and `evaluation_vault`.

## Non-negotiable invariants that must survive every change

- **Cryptographic Anonymity Decoupling**: `evaluation_clearances` records that a specific `student_id` completed an evaluation for a `course_section_id` and holds the signed clearance token. `evaluation_vault` stores the submitted 5-cluster Likert ratings (25 items across 5 clusters, backward-compatible with $\ge 20$-item instruments), structured qualitative responses, PII-scrubbed narrative comment, salted `comment_hash`, and NLP tags. **Never add `student_id`, `user_id`, `clearance_id`, IP address, session ID, or sub-second correlation timestamps to `evaluation_vault` or `security_audit_logs`.**
- **No Quick Tools or Demo / Cheat Shortcuts in Production**: Never reintroduce demo role switchers, Quick Tools sections, one-click auto-login buttons, dwell-timer skip buttons, straight-line auto-fill buttons, or proctor bypass controls anywhere in Vue components, Pinia stores, or API routes (`Group 38` anti-demo regression gate). Authentication uses seeded database accounts (`EvaluaTechDemoSeeder`) verified via bcrypt and signed Bearer tokens.
- **Evaluation Participation Tracking (Zero Permits)**: Pamantasan ng Lungsod ng Pasig does not gate final examination permits on student evaluations. The system tracks evaluation completion progress and identifies students with incomplete evaluations for institutional follow-up without linking student identities to submitted responses.
- **Submission Idempotency & Concurrency (`FT-02`)**: Every evaluation submission must carry a `submission_key` verified inside an atomic `DB::transaction()` after acquiring a pessimistic row lock (`SELECT ... FOR UPDATE`) on the enrollment/clearance state. Repeated clicks or network retries must return the original clearance token without inserting duplicate vault records.
- **Response Authenticity & Timing Policy**:
  - **Mandatory Timing Policy**: Students are permitted to submit completed evaluations whenever they are ready without an artificial minimum waiting duration or maximum answering limit (`dwell_time_seconds >= 0`). Only negative durations (`< 0`) or forged start tokens are rejected with HTTP `422`. Submissions are governed strictly by administrator-controlled evaluation windows (`starts_at`, `ends_at`, `Asia/Manila`).
  - **Straight-Lining Guard ($\sigma^2 = 0$)**: Compute population variance $\sigma^2$ across all submitted Likert ratings. If $\sigma^2 = 0$ and `confirm_uniform` is false, reject with a confirmation challenge; if confirmed (`confirm_uniform = true`), accept and set `is_straight_lined = true` in `evaluation_vault`.
- **Double-Blind Faculty Visibility Lock**: Faculty members cannot view quantitative ratings, score distributions, action plans, or sentiment summaries for any section unless both `term_grades_submitted = true` AND `registrar_lock = true`. Hiding a Vue button is not authorization; enforce `EnsureDoubleBlindUnlocked` on the server.
- **Departmental & College Tenant Containment (`IDOR / BOLA`)**: Department Chairs (`chair`) are strictly scoped to their assigned `department_id` across overview, heatmap, longitudinal, quartile, and Quivr Second Brain insight endpoints (`HTTP 403` on cross-department probes). College Deans (`dean`) are strictly scoped to their assigned college (`college_name`), and querying with an omitted `department_id` defaults strictly to all departments in their assigned college, preventing institution-wide data leakage.
- **Dean Exception Watchlist Thresholds**: Flag any instructor on the administrative watchlist when their mean Likert score is $< 3.50$ OR their negative sentiment comment share exceeds $35\%$ (dynamically tunable by Registrar/Admin within validated bounds).
- **63-Control Security Maxxxxxing Posture**: Maintain `63 / 63 ENFORCED` controls across OWASP headers (`CSP`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `X-Robots-Tag: noindex, nofollow`), path-traversal & `.env`/`.map` blocking (`403`), operator-injection rejection (`422`), sliding-window login rate limiting (`429`), constant-time bcrypt verification, `sessionStorage`-default token storage, `sanitizeRedirectPath` open-redirect protection, signed HMAC-SHA256 webhooks with nonce replay rejection (`409`), loopback SSRF allowlisting (`ALLOWED_NLP_HOSTS`, $\le 2.0\text{ s}$ timeout), and `sourcemap: false` in `vite.config.js`.
- **Resilient NLP Fallback**: Student evaluation submissions and exam clearance token issuance must never fail or block if the Python Flask daemon is offline; `AnalyticsClientService` must enforce a bounded $\le 2.0\text{ s}$ timeout and fall back to deterministic local `calamanCy`+VADER lexicon classification while queuing asynchronous retry processing.
- **Additive Migrations Only**: Never rewrite an already-verified migration to alter schema state; add a new forward migration and preserve test database isolation.
